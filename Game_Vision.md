# Game Vision - Eldritch Aquarium

**Version**: 1.0 (Fresh Incremental Pivot)  
**Date**: 2026-06-03  
**Brand**: Uncanny Mercantile

## Core Fantasy
You run a bizarre interstellar pet supply business. Your underwater tank is the heart of the operation. Order shady shipments from the eldritch void, watch shipping containers physically drop into the tank, crack them open for random organs, and feed your growing collection of cosmic pets. The more you scale, the weirder and more powerful your pets become.

**Tone**: Playful uncanny horror with light humor. Madness effects exist but lean fun and absurd rather than purely dark (pets temporarily eating UI elements, reality glitches that are mechanically useful, shipping labels like "100% Safe Definitely™").

## Core Gameplay Loop
1. **Acquire Resources** — Order shipments via upgraded shop
2. **Physical Delivery** — Containers drop into the underwater play space
3. **Unboxing** — Click containers to release 2-3 random organs
4. **Pet Management** — Feed organs to pets, evolve them, discover synergies
5. **Economy & Risk** — Manage pollution (boosts growth but triggers funny madness events)
6. **Progression** — Upgrade shop, unlock new pet species, prestige for bigger tanks and multipliers

## Key Systems

### Visual Style
- Main gameplay is a **zoomed-in underwater tank** (Mario-style aquatic side or top-down view)
- Lab elements become secondary UI/background only
- Vibrant yet eerie underwater aesthetic with particle effects, bubbles, and eldritch glows

### Economy & Resources
- Biomass, Void Essence, Sanity Shards, Pollution
- Multiple currencies with conversion loops
- Pollution as core risk/reward mechanic

### Pets
- Central focus of the game
- Start simple, evolve into complex eldritch forms
- Synergies, special abilities, and personality quirks

### Progression
- Upgradable Shop/Distributor (better shipments, more frequent drops)
- Pet-rooted upgrade tree
- Prestige system (increased tank capacity, permanent bonuses, new starting options)

### Madness Mechanics
- Humorous fourth-wall breaks and visual gags
- Temporary mechanical effects that create fun moments rather than frustration

## Design Goals
- Addictive "one more shipment" incremental gameplay
- Strong visual feedback and juicy interactions
- Accessible but deep strategic choices
- Reuse existing assets where possible, create new underwater-themed ones

## Success Criteria
- Core loop feels satisfying within first 10 minutes
- Players excited to see pets evolve and grow
- Pollution and madness create memorable moments without being punishing
