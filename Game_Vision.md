# Game Vision - Eldritch Aquarium
**Version**: 1.4 (Starter Trio + Active Consumption + Prestige Tree)  
**Date**: 2026-06-08  
**Brand**: Uncanny Mercantile

## Core Fantasy
You run a shady interstellar pet supply business. Order suspicious shipments via comic book ads, crack open containers, feed and evolve eldritch pets in your tank. Manage resources, balance Pollution, and scale through prestige resets. Pets start cute and become reality-bending horrors. Every run ends in inevitable death (via Pollution or Overburden) that feeds into Fragments and permanent upgrades.

**Tone**: Playful uncanny horror with light humor. Madness events are fun and useful.

## Core Gameplay Loop
1. **Comic Ad / Shipment** → Themed drop based on active starter (medium/large/small focus).
2. **Food/Organ Drops** → Mixed sizes with RNG (60-85% preferred via prestige).
3. **Active Tank Tending** → Pets auto-consume matched sizes; player clicks released resource globs for bonuses. Mismatches lead to rot → Pollution.
4. **Pet Evolution** → Consumption-gated (5 stages, 2 choices each). Starter evolutions reset on prestige.
5. **Pollution Management** → Dampens gains; high levels trigger comics and death.
6. **Prestige/Reset** → Via Fragments from deaths/sets. Spend in main upgrade tree (shop improvements, evolution speed, etc.).
7. **Discovery** → RNG shipments, comic panels with alien scientists, madness events.

## Key Systems

### Resources (4 Core + Meta)
See **Resources_Economy.md**.

### Shipments & Consumption
- Starter-matched themes with prestige-improved ratios (60/40 base → 85/15).
- Player clicks released Insight/Biomatter globs.
- Rot releases partial resources but spikes Pollution.
- Remora: Large preference + unique Pollution/Overburden loop.

### Pets & Evolutions
- **One Starter per Run** (Goldfish default; RNG on unlocks).
- **9 Total Pets** in 3 categories: Starters (tone-setters), Boosters, Interactors.
- **5 Stages × 2 Choices** (10 decisions). Consumption-based thresholds (reduced by prestige tree).
- Full details in **Pets.md** (new).

### Prestige & Main Upgrade Tree
- Fragments from pet deaths + set completions.
- Central tree unlocks shop improvements, Pollution tolerance, evolution speed, starter RNG, multi-pet scaling, etc.
- Resets pet states for fresh evolution paths.

### Comics & Madness
- Threshold-triggered 4-panel scientist comics guide progression and show escalating madness.
- Hidden Madness tracker drives goofy events and visuals.

## Design Goals
- Active but forgiving tank tending.
- Distinct playstyles per starter.
- Clear progression via comics/tree without tutorials.
- Strong replay via resets and builds.
