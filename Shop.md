## Shipment Tiers (Bronze / Silver / Gold)
- **Bronze** (Slot 1): 2 organs, baseline rarity distribution. Cheapest/spammable.
- **Silver** (Slot 2): 3 organs, improved higher-rarity chances.
- **Gold** (Slot 3): 4 organs, best base rarity odds. Premium pricing.
- Each tier increases quantity by +1 organ and boosts higher-rarity probability.
- Theming remains starter-biased (60/40 → 85/15 preferred sizes via prestige).
- **Prestige Upgrades**: Increase prices across all tiers but dramatically improve rarity rates, add quantity bonuses, or add minimum rarity floors. Creates "pay more for vastly better" incremental scaling.

## Slot Progression & Gating
- **Slots 1-3**: Always available (one per tier).
- **Slots 4 & 5**: Unlock via prestige tree (after secondary pets available). Used for ordering **additional pets** from other categories. Pricing + cooldowns heavily gate duplicates of the same category (encourages collection over stacking).
- **Slot 6: Victory / Apex Research Goal**: End-game "bajillion" shipment. Massive fixed Insight + Biomatter payload + final event trigger (Madness climax / super-evolution / prestige enabler). Extremely high cost; possible collection/madness prerequisites.

## Organ Generation & Economy
- 3 sizes (small/medium/large) × 5 rarities = **15 organ assets**.
- **Fixed base resources per rarity** (e.g., Common Small = low Insight/Biomatter). Prestige, pet synergies, and temporary buffs provide the huge multiplicative leaps.
- Mnemonic Fragments rewarded for discovering all 5 rarities in one size set.
- Uneaten food → rot (partial resources + Pollution spike).
