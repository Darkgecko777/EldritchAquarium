# Shop & Shipments
**Version**: 1.3  
**Date**: 2026-06 (updated)  
**Updated**: Food-mutation theme, no egg, complimentary sample feed pack, normal goldfish start.

## Catalog UI (TitleScreen / Comic Ad)
- All shipments (exotic feed orders) ordered via dynamic comic catalog (6 slots total). Title screen is the vintage "exotic fish food & supplements" ad/catalog.
- First order for a new run is a special complimentary sample pack (2-3 high-quality starter feed items to kickstart mutations). No egg or pet acquisition — the normal goldfish specimen is already in the tank.
- Catalog shows tiered options with previews, costs, and lock icons.

## Shipment Tiers (Bronze / Silver / Gold) — Exotic Feed Orders
- **Bronze** (Slot 1): 2 feed items, baseline rarity distribution. Cheapest/spammable everyday blend.
- **Silver** (Slot 2): 3 feed items, improved higher-rarity (more potent mutation fuel) chances.
- **Gold** (Slot 3): 4 feed items, best base rarity odds. Premium pricing.
- Each tier increases quantity by +1 and boosts higher-rarity probability (stronger mutations, better yields).
- Theming remains specimen-biased (60/40 → 85/15 preferred sizes via prestige).
- **Prestige Upgrades**: Increase prices across all tiers but dramatically improve rarity rates, add quantity bonuses, or add minimum rarity floors. Creates "pay more for vastly better" incremental scaling for your mutation program.

## Slot Progression & Gating
- **Slots 1-3**: Always available (one per tier).
- **Slots 4 & 5**: Unlock via prestige tree (after secondary pets available). Used for ordering **additional pets** from other categories. Pricing + cooldowns heavily gate duplicates of the same category (encourages collection over stacking).
- **Slot 6: Victory / Apex Research Goal**: End-game "bajillion" shipment. Massive fixed Insight + Biomatter payload + final event trigger (Madness climax / super-evolution / prestige enabler). Extremely high cost; possible collection/madness prerequisites.

## Feed Generation & Economy
- 3 sizes (small/medium/large "pellets/chunks/supplements") × 5 rarities = **15 feed variants**.
- **Fixed base resources per rarity** (e.g., Common Small = low Insight/Biomatter). Prestige, specimen synergies, and temporary buffs provide the huge multiplicative leaps. Higher rarity = more potent mutations and better yields.
- Mnemonic Fragments rewarded for discovering all 5 rarities in one size set (visual achievement + comic).
- Uneaten feed → rot (partial resources + Pollution spike).
